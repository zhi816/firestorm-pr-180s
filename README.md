# 炎上大作戰：危機公關 180 秒

**Firestorm PR: 180s Crisis Survival**

> 百萬訂閱一夕歸零，今晚你是全身而退，還是被釘在公審恥辱柱上？

一款網頁上的危機公關模擬遊戲。你扮演剛翻車的網紅，要在 180 秒內寫出道歉聲明。AI 會扮演 6 種網友留言公審你，再由 AI 裁判挑出聲明的漏洞、算出掉粉數，最後產生一張突發新聞頭條圖卡。

期末專題作業。純前端單一網頁，部署在 GitHub Pages。

---

## 遊戲流程

| 階段 | 內容 |
| :--- | :--- |
| 1. 爆料登場 | 隨機抽一則翻車事件，亮出網友的三大質疑 |
| 2. 180 秒寫聲明 | 勾選公關策略（影片形式、話術），親手寫聲明稿 |
| 3. AI 公審 | 6 種人設的網友留言轟炸，AI 裁判打分、扣粉絲 |
| 4. 結局 | 4 種結局，加上可下載的新聞頭條圖卡 |

在時限內可以「緊急撤回」，依照 AI 挑出的毛病修改後重新送審（Human-in-the-loop Reflection 閉環）。

## 技術概要

- 單一 `index.html`（HTML + CSS + JS），不需要後端
- LLM：Groq（llama-3.1-8b-instant）或 Google Gemini，API Key 由玩家自己輸入，只存在瀏覽器
- 沒有 Key 或 API 故障時，自動改用內建的離線資料，展演時一定能玩
- 美術方向：像素 RPG × 社群介面（討論中，見 [決策紀錄](docs/log.md)）
