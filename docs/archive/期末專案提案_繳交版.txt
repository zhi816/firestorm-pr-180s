期末專案提案：《炎上大作戰：危機公關 180 秒》（Firestorm PR: 180s Crisis Survival）
================================================================================

一、 基本資訊與專案定位
--------------------------------------------------------------------------------
1. 專案名稱：《炎上大作戰：危機公關 180 秒》（Firestorm PR: 180s Crisis Survival）
2. 提案學生：（請填寫 學校 / 系級 / 學號 / 姓名）
3. 專案類型：互動式網頁文字模擬遊戲（結合 Vibe Coding、多智能體 Prompt 工程與 LLM API）
4. 核心標語：「百萬訂閱一夕歸零，今晚你是全身而退，還是被釘在公審恥辱柱上？」
5. 部署形式：純前端單檔（index.html）託管於 GitHub Pages，零後端伺服器成本。


二、 專案背景與核心動機（Why）
--------------------------------------------------------------------------------
1. 現實痛點與時事話題：
   社群平台（Threads、Dcard、YouTube）時代，網紅翻車與品牌公關災難頻傳。多數危機聲明因充斥「佔用社會資源」、「推託責任給外包」等千篇一律的官腔套話，不僅未能滅火，反而引爆全網二次炎上。

2. 為什麼必須採用「生成式 AI」（非傳統寫死劇本遊戲）：
   傳統文字冒險遊戲只能透過固定選項跳轉寫死的結局，玩家玩過一次便失去新鮮感。
   本專案核心導入大語言模型（LLM），允許玩家自由輸入自訂的公關道歉聲明稿，由 AI 即時進行深層語義剖析、邏輯漏洞挑錯，並模擬多樣化網友的辛辣吐槽與輿論風向，具備不可替代的動態隨機性與互動張力。


三、 核心功能與遊戲流程（What）
--------------------------------------------------------------------------------
本遊戲採單回合、3 分鐘一局的高節奏危機處置模擬，包含 4 大遊戲階段：

【概念流程圖（Gameplay Flowchart）】

   ┌──────────────────────────────────────────────┐
   │ 階段 1：突發危機爆料 (Crisis Trigger)        │
   │ 隨機抽取翻車事件 ＋ 螢幕紅色警報閃爍          │
   └──────────────────────┬───────────────────────┘
                          │
                          ▼
   ┌──────────────────────────────────────────────┐
   │ 階段 2：180 秒生死應變 (PR Tactic & Drafting) │
   │ 戰術標籤勾選 ＋ 玩家親撰聲明稿 (支援AI草稿)  │
   └──────────────────────┬───────────────────────┘
                          │
                          ▼
   ┌──────────────────────────────────────────────┐
   │ 階段 3：AI 輿論審判室 (AI Backfire Simulator)│
   │ 6+ 鮮明人設網民留言雨 ＋ 數值心電圖劇烈扣血  │
   └──────────────────────┬───────────────────────┘
                          │
                          ▼
   ┌──────────────────────────────────────────────┐
   │ 階段 4：終局命運與頭條圖卡 (Outcome & News)   │
   │ 判定 4 大結局 ＋ Canvas 匯出蘋果/TVBS 突發新聞│
   └──────────────────────────────────────────────┘

【4 大階段詳細規格說明】：

階段 1：突發危機爆料（Crisis Trigger）
- 進入遊戲時發出警報音效，由內建事件庫隨機抽取一則經典爭議事件（例如：自創潮牌驚爆淘寶 39 元貼牌連簡體吊牌都沒剪、知性 YouTuber 劈腿 4 人借花獻佛、手搖飲珍珠掉水槽等）。
- 畫面展示爆料事證與「網民三大核心質疑（必答題）」。
- 初始數值：粉絲數 1,500,000、炎上指數 75%（高危險）、廠商信任度 30%。

階段 2：180 秒生死應變（PR Tactic & Statement）
- 啟動 180 秒倒數計時器。
- 戰術策略複選（Checkbox）：影片形式（黑底白字嘆氣 / 憔悴素顏鞠躬 / 律師陪同）＋ 公關話術（全額退款 / 推給外包 / 曬身心科病歷 / 保留法律追訴權）。
- 親撰聲明稿（Input Box）：玩家在輸入框自由打字回應爭議；若詞窮可點擊「AI 公關罐頭小幫手」自動生成充滿套話的初稿再手動修改。

階段 3：AI 輿論公審室（The AI Backfire Simulator）
- 點擊【發布聲明，聽天由命】後，畫面右側高速刷出至少 6 種不同立場的網民留言瀑布。
- 儀表板像心電圖般劇烈波動，實時扣除或回補粉絲數、計算炎上指數。

階段 4：終局命運與頭條圖卡（Outcome & Headline）
- 依據最終數值判定 4 大極端結局之一：
  1. 【身敗名裂，徹底封殺】：掉粉超百萬，廠商求償，夜市擺攤。
  2. 【越描越黑，二度炎上】：漏洞百出，道歉文被剪成迷因鬼畜瘋傳。
  3. 【黑紅也是紅，轉型爭議巨星】：形象全毀但爭議破表，轉型狂暴系直播主。
  4. 【教科書級公關滅火】：誠懇認錯退款，粉絲逆勢回流，公關業界神級範本。
- 利用 HTML5 Canvas 自動繪製「蘋果 / TVBS 風格突發即時新聞頭條圖卡」（紅底白字突發跑馬燈、大頭貼、AI 辛辣下標、掉粉數據），提供玩家一鍵下載圖片分享至社群平台。


四、 生成式 AI 技術架構規劃（How - 課堂理論深度整合）
--------------------------------------------------------------------------------
本專案嚴格遵循課堂簡報《08教AI做事的方法.pdf》中，吳恩達（Andrew Ng）提出的 4 大 AI Agent 設計模式，將「Reflection（反思／評論員模式）」與「Multi-Agent Collaboration（多智能體協同）」作為專案技術骨幹：

【多智能體協同與 Reflection 資料流架構圖】

                     【前端網頁 (Input)】
          (翻車事件資料 ＋ 玩家勾選策略 ＋ 聲明稿全文)
                          │
         ┌────────────────┴────────────────┐
         ▼                                 ▼
   【AI 1：網民大軍】             【AI 2：公關裁判長】
 (Multi-Agent 協同演出)         (Reflection 評論員模式)
 職責：感性模擬 6+ 人設留言     職責：理性漏洞挑錯與量化評分
         │                                 │
         │ (留言資料串流)                  │ (評分與結局 JSON)
         └────────────────┬────────────────┘
                          ▼
              【前端遊戲引擎接收與渲染】
    (右側留言瀑布流 ＋ 儀表板數據扣除 ＋ Canvas 新聞產製)
                          │
             (可選加分功能：180秒時限內)
                          ▼
            【🚨 人機協同 Reflection 閉環】
      (玩家點擊「緊急撤回」，根據漏洞批改重修聲明二次送審)

1. 理論核心：吳恩達 Reflection（反思 / 評論員模式）
   - 作者（Generator / Author）：由玩家親自撰寫（或由 AI 小幫手生成初稿）的公關道歉聲明稿，即為系統的「初稿」。
   - 評論員（Critic / Evaluator）：由【AI 2：公關裁判長】擔任。嚴格符合課堂定義，專門挑出文章毛病、檢查核心爭議是否有如實回應、揪出甩鍋推諉邏輯。
   - 兩階段思維鏈（Chain-of-Thought, CoT）：
     * 質化分析（Qualitative）：逐句抓出 2~3 個致命邏輯漏洞（如：第一句假道歉、第二句光速甩鍋給廠商、未提供實質退款方案）。
     * 量化換算（Quantitative）：將漏洞嚴重性客觀映射為遊戲數值（誠意評分、甩鍋指數、扣粉數、炎上指數增減、結局代碼）。
   - 人機協同閉環機制（Human-in-the-loop Reflection）：
     若玩家在倒數時限內看見扣粉慘況，可點擊「緊急撤回重修」，根據 AI 剛剛挑出的漏洞修改公關稿後二次送審，完美達成「初稿 -> 評論挑錯 -> 修改重提」的完整 Reflection 閉環！

2. 協同模組：Multi-Agent Collaboration（多智能體協同）
   - 【AI 1：社群網民模擬器】：負責營造逼真的群體情緒，強制輸出至少 6 種極端鮮明的網民人設：
     1. 顯微鏡柯南（逐格抓微表情與文字矛盾）
     2. 激進黑粉（瘋狂人身攻擊與退追檢舉）
     3. 盲目護航粉（無腦死忠護航反遭圍剿）
     4. 昔日合作廠商（落井下石爆料私德）
     5. 蹭流量八卦創作者（預告今晚開台復盤）
     6. 迷因製造機（抓贅字狂做迷因梗圖）

3. 精確 I/O 規格定義（以 JSON 作為通訊標準）：
   - 輸入（前端打包給 AI 的 Context）：
     {
       "event_title": "自創潮牌驚爆淘寶貼牌",
       "core_inquiries": ["是否為淘寶同款", "是否全額退款", "為何刪除質疑留言"],
       "selected_tactics": ["黑底白字嘆氣", "推給外包廠商", "曬身心科病歷"],
       "player_statement": "對於佔用社會資源感到很抱歉...外包廠商把關不嚴..."
     }
   - 輸出（AI 裁判回傳之結構化 JSON）：
     {
       "qualitative_analysis": {
         "attitude": "避重就輕，推卸責任",
         "critical_flaws": [
           "第一段道歉虛應故事，第二段立刻將品管責任推給外包廠商。",
           "完全無視買家的退款訴求，通篇未見任何賠償方案。"
         ],
         "expert_verdict": "典型提油救火的災難級公關稿，引爆全網二次公憤。"
       },
       "quantitative_scores": {
         "sincerity_score": 35,
         "shirking_index": 85,
         "fan_change": -850000,
         "flame_delta": 25,
         "ending_code": "ENDING_BACKFIRE",
         "breaking_news_headline": "【獨家】淘寶貼牌翻車！百萬網紅曬病歷喊告遭痛批：當全網是盤子？"
       }
     }

4. 系統防呆與資安保證（Robustness & Security）：
   - Markdown 標籤清洗防呆：前端使用正則表達式自動剃除 LLM 可能夾帶的 ```json 標籤，保證 JSON.parse 零報錯。
   - 輸入字數防呆：輸入空白或亂碼直接硬性判定為「神隱裝死、逃避責任」，炎上指數直接補滿 100% 暴斃。
   - 展演離線智囊庫（Fallback Cache）：內建 2 組本機預設資料，若展演現場 API 逾時或斷網，自動無縫切換為離線展示模式，保障展演 100% 不翻車。


五、 實作方式與部署規劃（Implementation）
--------------------------------------------------------------------------------
1. 開發方式：以 Vibe Coding 協同模式編寫單一前端檔案（index.html），內嵌 CSS 視覺樣式、JavaScript 狀態機與 HTML5 Canvas 動態繪圖。
2. 佈局規劃（三欄沉浸式介面）：
   - 左側：紅色警報動畫、180 秒倒數計時器、心電圖式粉絲數暴跌折線圖。
   - 中央：公關策略勾選區、聲明稿文字輸入框、醒目的發布與撤回按鈕。
   - 右側：仿 Threads / YouTube 深色卡片動態留言串流。
3. 部署方式：託管於 GitHub Pages 靜態網站，使用者點開網址即可直接遊玩。
4. 金鑰安全機制：網頁右上角設計「⚙️ 設定」彈窗，使用者自行輸入 Groq / Gemini API Key 並存於瀏覽器 localStorage，GitHub 原始碼完全乾淨，零資安洩漏風險。
