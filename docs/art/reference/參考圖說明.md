# 美術參考圖包（像素風格樣張 v3）

本資料夾把 [像素風格樣張_v3.html](../samples/像素風格樣張_v3.html) 的畫面整理成**靜態圖片與可讀原始碼**，讓其他 AI 或組員不必執行網頁也能看懂目前的視覺方向。

- 美術方向與否決紀錄：[DESIGN.md](../../../DESIGN.md)
- 詳細數值（色碼、字級、元件、版面）：[美術設計規格書.md](../美術設計規格書.md)
- 本資料夾的圖片都是由 v3 樣張自動截圖產生，**畫面以樣張與規格書為準，圖片只是快照**；規格更新後若圖片過時，要重新產生。

## 二、原始碼

| 檔案 | 說明 |
| :--- | :--- |
| [像素風格樣張_v3_原始碼.html](像素風格樣張_v3_原始碼.html) | v3 樣張的可讀版原始碼。字型位置是 `/*FONT*/` 佔位字，**直接開啟會改用備用字型**；要看正確效果請開 [samples/像素風格樣張_v3.html](../samples/像素風格樣張_v3.html)（已內嵌字型） |

原始碼裡可以直接查到的東西：

- CSS 變數（Design Token）：檔案開頭 `:root` 區塊
- 點陣角色：`IVY`（小艾）、`LAW`（律師）、`HEAD` 與 `PERSONAS`（酸民頭像）的字串陣列
- 道歉影片圖層：`renderVideo()`
- 新聞卡繪製：`drawCard()`；四種結局文字：`ENDINGS`

## 三、給其他 AI 的使用方式

1. **能讀檔案的 AI**（Claude Code、Codex、Antigravity 等在本 repo 工作時）：先讀 [AGENTS.md](../../../AGENTS.md)、[DESIGN.md](../../../DESIGN.md)，再看本資料夾的圖片與原始碼。
2. **只能上傳圖片的 AI**（網頁版聊天機器人）：上傳需要的圖片，並附上下面這段說明。

```text
這是期末專題遊戲《炎上大作戰：危機公關 180 秒》的美術參考圖。
風格是「像素 RPG × 社群」：網路公審被做成 RPG 戰鬥，粉絲數＝HP、炎上度＝怒氣條、
酸民留言＝攻擊訊息。介面固定深夜藍底（#0c1230），可按的按鈕用金色（#f5b82e），
傷害與警告用紅色（#ff4d5e）。中文像素字型是俐方體 11 號（Cubic 11）。
場景只用現代物件（手機、補光燈、麥克風），不用奇幻元素；新聞台、平台、人物都是虛構的
（炎上新聞台 FNN、炎串、爆料版）。請沿用這個風格，不要改成擬真社群 App 介面。
```

## 四、重新產生圖片

圖片由 v3 樣張以 Playwright 自動截圖（電腦 1360×900、手機 390×844），新聞卡直接取自頁面產生的 1280×720 圖片，角色圖用頁面內的繪圖函式產生。樣張改版（v4 之後）時，請建立新的參考圖資料夾或在檔名加版本號，不要覆蓋本資料夾的 v3 快照。
