## 一、美術方向【定案】

### 1. 一句話

> **網路公審是一場 RPG 戰鬥。** 玩家是被圍攻的網紅，酸民是敵人，聲明稿是必殺技。

用像素 RPG 的介面語言（血條、對話框、指令選單、Boss 登場），包住現代社群的內容（貼文、留言、訂閱數、直播）。

### 2. RPG 對照表【定案】

| 遊戲裡的東西 | RPG 化的呈現 |
| :--- | :--- |
| 粉絲數 | HP 血條，掉粉＝扣血 |
| 炎上度 | 火焰條（敵人怒氣） |
| 廠商信任度 | MP 條 |
| 爆料事件 | Boss 登場：「BOSS 出現了！」 |
| 策略標籤 | 指令選單（技能、道具） |
| 聲明稿 | 必殺技，發布＝出招 |
| 6 種酸民 | 6 隻敵人，各有像素頭像與代表色 |
| 酸民留言 | 攻擊訊息：「激進黑粉 使出了【退訂檢舉】！效果絕佳！」 |
| 結局 | ENDING 畫面＋像素新聞卡＋診斷書 |

### 3. 社群感怎麼保住【定案】

- 留言卡保留「頭像＋暱稱＋人設標籤＋內容＋愛心數」的結構。
- 影片區有訂閱數、讚／倒讚、LIVE 標籤、播放條。
- 手機公審時，留言像直播聊天室疊在影片上。

### 4. 世界觀限制【定案】

- 場景道具用現代物件：手機、環形補光燈、麥克風、桌子、海報。**不用城堡、寶劍、魔法**。
- 所有品牌、平台、人物都是虛構的（見第十二章）。

### 5. 遊戲調性【未定】

偏「緊張」（壓迫感）還是偏「好笑」（荒謬鬧劇）還沒有明確定案。目前樣張兩者都有：倒數和扣血負責緊張，酸民台詞和結局標題負責好笑。

## 二、工作方式【定案】

1. 程式先做灰盒版，顏色、字型、尺寸全部用第三章的 CSS 變數。
2. 美術調整只改變數和樣張，不回頭重寫程式。
3. 新的視覺嘗試先做成樣張（`samples/像素風格樣張_vN.html`），確認後再寫進本文件。

## 三、Design Token【暫定】

數值取自樣張 v3，正式版直接複製使用。

```css
:root {
  color-scheme: dark;

  /* 底色與面板（深夜藍） */
  --night:   #0c1230;  /* 網頁底色，上面有 12px 點狀格線 */
  --panel:   #18224c;  /* 面板 */
  --panel-2: #212e63;  /* 面板內的次層：留言卡、標籤 */
  --hi:      #34458a;  /* 面板左上亮邊 */
  --lo:      #0f1738;  /* 面板右下暗邊、輸入底色 */
  --line:    #04071a;  /* 像素外框（近黑） */

  /* 文字 */
  --ink: #eef1ff;
  --dim: #97a3d6;

  /* 主色：金色＝可以按的東西 */
  --gold:    #f5b82e;
  --gold-hi: #ffe08a;
  --gold-lo: #b06f12;

  /* 語意色 */
  --red:   #ff4d5e;  /* 傷害、扣粉、LIVE、警告 */
  --flame: #ff8a1f;  /* 炎上條 */
  --cyan:  #45d0ff;  /* MP 條、鍵盤焦點框 */
  --pink:  #ff6fae;  /* 愛心數 */
  --green: #4fdc7a;  /* HP 條（低於約 73% 變紅） */

  /* 字型 */
  --px:   "Cubic11", "Noto Sans TC", sans-serif;  /* 像素字 */
  --long: var(--px);                               /* 長文字，見第四章【未定】 */
}
```

**配色規則**【暫定】

- 金色只給「可以按的主要按鈕」和「選中的指令」，不要拿來裝飾。
- 紅色只表示「壞事」：傷害、扣粉、警告。
- 每個遊戲階段**不再換整體主色**（v1 的做法取消），改由結局畫面用結局色收尾（第十章）。

## 四、字型

### 1. 像素字【定案】

- **俐方體 11 號（Cubic 11）**，免費授權，支援繁體中文。
- 只把頁面用到的字做成子集，再以 base64 內嵌，維持單一 `index.html`（樣張約 30KB）。

### 2. 字級【暫定】

像素字只有在 **12px 的倍數**最清楚，其他大小會糊。

| 字級 | 用途 |
| :--- | :--- |
| 12px | 標籤、數值說明、留言者名稱、分頁按鈕、聊天室留言 |
| 18px | 手機版對話框、手機版按鈕（會微糊，可接受） |
| 24px | 對話框、標題、主按鈕、倒數（手機） |
| 36px | Logo、倒數（電腦）、結局標題（電腦） |

### 3. 長文字用哪種字【未定】

聲明稿、爆料內文、留言內容這類長文字：

- 選項 A：也用像素字（風格一致，讀久會累）
- 選項 B：用 Noto Sans TC 一般字型（好讀，風格較弱）

樣張 v1～v3 底部「說明」有切換鈕可以比較。程式用 `--long` 變數控制，決定後只改一行。

## 五、像素 UI 元件【暫定】

| 元件 | 做法 |
| :--- | :--- |
| **面板** `.pn` | 用 4 個方向的 `box-shadow` 做出缺角的像素外框，再用 inset 做左上亮、右下暗的立體邊 |
| **面板標題** `.pn-title` | 小方塊標籤，金色字，像 RPG 視窗的標題 |
| **主按鈕** `.btn` | 金底深字＋立體邊，按下往下移 2px |
| **次按鈕** `.btn.ghost` | 深藍底白字，同樣的立體邊 |
| **指令** `.cmd` | 深色方塊，左邊小方點；選中後變金框，方點變成 ▶ 游標 |
| **血條** `.bar` | 深色槽＋上亮下暗的雙色條，寬度變化用 `steps()` 一格一格跳 |
| **留言卡** `.cm` | 48px 頭像＋暱稱＋人設色標籤＋內容＋愛心數＋扣粉數 |
| **對話框** `.dlg` | 底部長條，左邊頭像，24px 文字，右下閃爍的 ▼ |
| **輸入框** | 近黑底＋藍色內框，長文字字型 |
| **診斷書** `.doc` | 米黃紙張（`#efe6cf`）深色字，跟深藍介面做對比，一看就是「文件」 |
| **頂部狀態列**（手機） | 倒數＋HP＋炎上，固定在最上方 |
| **底部分頁**（手機） | 5 格：爆料／寫稿／公審／結局／說明，選中變金色，公審有紅點數字 |

所有可以按的東西都要有鍵盤焦點框（`--cyan` 2px 外框）。

## 六、道歉影片（主視覺）【暫定】

### 1. 畫面

- Canvas 內部解析度 **128×72**（16:9），用 `image-rendering: pixelated` 放大。
- 下方有播放條（跟 180 秒倒數連動）、影片標題、頻道名稱與訂閱數（＝粉絲數）、讚與倒讚。

### 2. 圖層（由下到上）

| 圖層 | 內容 | 連動的策略 |
| :--- | :--- | :--- |
| 背景 | 紫色房間牆、層架、植物、海報、紅色螢幕 | 黑底白字 → 全黑 |
| 桌子 | 木桌、麥克風 | — |
| 補光燈 | 主角身後的環形燈 | — |
| 主角 | 小艾坐姿，含淚 | 素顏鞠躬 → 低頭＋降彩度 |
| 律師 | 站在右側 | 律師在旁 → 顯示 |
| 道具 | 桌上的診斷書 | 曬診斷書 → 顯示 |
| 字幕 | 玩家聲明稿的最後一句 | 黑底白字時改成置中＋「（深深嘆一口氣）」 |
| 介面 | LIVE 標籤、直播聊天室（手機公審時） | — |

### 3. 公審時的直播模式（手機）

畫面裁成正方形（`object-fit: cover`），隱藏字幕，留言從左下冒出，最多 3 則、每則 1 行。律師放在 x=82，裁切後仍看得到。

## 七、角色與頭像（程式繪製點陣圖）【暫定】

全部用字串陣列描述像素，再用 Canvas 畫出來，**不需要任何圖檔**。左右對稱的角色只寫左半邊，程式自動鏡像。

### 1. 角色

| 角色 | 尺寸 | 變化 |
| :--- | :--- | :--- |
| 小艾（玩家扮演的網紅） | 28×28 | 坐姿含淚／鞠躬（只露頭頂）／憔悴（降彩度）／灰階（身敗名裂）／墨鏡（黑紅巨星）／微笑（公關奇蹟） |
| 律師 | 20×22 | 眼鏡、深色西裝、紅領帶 |

三個爆料事件**共用同一個主角**，只換影片標題和頻道內容。

### 2. 酸民頭像（12×12，放大成 48px）

| 人設 | 代表色 | 特徵 |
| :--- | :--- | :--- |
| 激進黑粉 | 紅 `#ff4d5e` | 黑色帽 T、怒眉、張嘴、臉紅 |
| 顯微鏡柯南 | 青 `#45d0ff` | 眼鏡、紅領結 |
| 盲目死忠粉 | 粉 `#ff6fae` | 金髮、愛心眼、眼淚 |
| 迷因製造機 | 金 `#f5b82e` | 綠髮、小丑紅鼻、大笑 |
| 昔日合作廠商 | 灰藍 `#8f9bd0` | 灰髮、西裝白領 |
| 蹭流量八卦客 | 橘 `#ff8a1f` | 拿著西瓜（吃瓜） |

代表色同時用在留言卡的人設標籤和聊天室暱稱。

### 3. 之後要升級的話

如果想要更精緻的角色，可以改用 AI 生成的像素圖，但 AI 生的像素圖格子常常不整齊，要再手動修正。程式的圖層架構不用改，只換圖。

## 八、動畫【暫定】

像素風的動畫一律用 `steps()`，一格一格跳，不要平滑過渡。

| 動畫 | 做法 | 時間 |
| :--- | :--- | :--- |
| 留言卡滑入 | 從右 24px 滑入＋淡入，`steps(4)` | 0.4s |
| 聊天室留言 | 從下 12px 冒出，`steps(3)` | 0.35s |
| 血條變化 | 寬度 `steps(12)` | 0.6s |
| 畫面震動 | 扣粉超過 5 萬時，整個戰場左右晃 | 0.3s |
| 倒數變紅閃爍 | 剩 30 秒，`steps(2)` 閃爍 | 0.5s 循環 |
| 對話框 ▼ | 閃爍 | 0.8s 循環 |
| HP 扣血數字 | 手機狀態列的 HP 數字短暫變成紅色扣血量 | 1.2s |

`prefers-reduced-motion` 開啟時，震動、閃爍、滑入全部關掉。

## 九、版面【暫定】

### 1. 電腦版（寬度大於 1080px）：三欄一次看完

```
┌ Logo ──────────────────────────────────── 倒數 ┐
├ 左：狀態／Boss 貼文／三大質疑 ┬ 中：道歉影片＋指令＋聲明稿 ┬ 右：留言區 ┤
├ 對話框（攻擊訊息） ─────────────────────────────┤
└ 結局：蓋在畫面上的全螢幕層，可按「回到公審」或 Esc ┘
```

寬度 761～1080px：左欄移到下方變兩欄。

### 2. 手機版（寬度 760px 以下）：一次一個階段，不捲動

```
┌ 頂部狀態列：倒數｜HP｜炎上 ┐
│                          │
│   目前階段的畫面          │
│                          │
└ 底部分頁：爆料 寫稿 公審 結局 說明 ┘
```

| 階段 | 畫面內容 |
| :--- | :--- |
| 爆料 | Boss 貼文＋三大質疑＋「接招！開始寫聲明」 |
| 寫稿 | 小影片＋指令（兩欄、不顯示說明小字）＋聲明稿＋發布鈕 |
| 公審 | 方形直播畫面＋聊天室＋對話框＋「緊急撤回修改」「重播公審」 |
| 結局 | 結局標題＋新聞卡＋診斷書＋重新挑戰（這頁可以捲動） |

- 階段改變時自動切換分頁；玩家也可以點分頁回去看。
- **專注寫稿模式**：點聲明稿輸入框時隱藏指令區，讓字幕預覽和輸入框留在鍵盤上方（實機效果待確認）。
- 頂部和底部都要加上手機安全區域的邊距。

## 十、結局畫面【暫定】

### 1. 四種結局

| 代碼 | 標題 | 結局色 | 印章 | 新聞標籤 | 大頭照 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `ENDING_DESTROYED` | 身敗名裂，徹底封殺 | 紅 `#ff3b4f` | 身敗名裂 | 獨家 | 灰階 |
| `ENDING_BACKFIRE` | 越描越黑，二度炎上！ | 橘 `#ff8a1f` | 二度炎上 | 獨家 | 含淚 |
| `ENDING_CONTROVERSIAL` | 黑紅也是紅，轉型爭議巨星 | 紫 `#c86bff` | 黑紅巨星 | 爭議 | 戴墨鏡 |
| `ENDING_PERFECT` | 教科書級公關滅火 | 綠 `#4fdc7a` | 公關奇蹟 | 暖聞 | 微笑不哭 |

結局色用在：標題外框、標題文字、新聞卡印章。

### 2. 像素新聞卡

先畫 **320×180** 的點陣圖，再放大 4 倍輸出成 **1280×720** 的圖片。

```
y=0   ┌ 突發 BREAKING（黃）│ 紅條        炎上新聞台 FNN ● LIVE ┐
y=16  ├──────────────────────────────────────────────────────┤
y=24  │ ┌─大頭照框 100×104─┐  [獨家]                           │
y=42  │ │                  │  ┌ 黃底標題（12px，最多 4 行）─┐  │
      │ │   小艾 ×3 倍     │  └────────────────────────────┘  │
      │ │                  │               ╔═ 印章（傾斜）═╗   │
      │ └ 小艾 Ivy ────────┘               ╚══════════════╝   │
y=136 ├ 掉粉 −374,000  剩餘 1,126,000  誠意 35/100（深藍條）─┤
y=156 ├ [名醫診斷] 典型提油救火：道歉一句，甩鍋三句。（白底）─┤
y=180 └──────────────────────────────────────────────────────┘
```

- 中文要自己逐字量寬度斷行（Canvas 不會自動換行）。
- 畫之前先等像素字型載入完成。
- **存檔方式**【暫定】：輸出成圖片，玩家長按或按右鍵存檔。部署到 GitHub Pages 後可再加下載按鈕（預覽環境會擋下載）。

### 3. AI 公關名醫診斷書

米黃紙張樣式，內容依序：

1. 標題「AI 公關名醫診斷書」＋病歷號
2. 病患（小艾 Ivy）、診斷（＝ AI 回傳的 `core_attitude`）
3. 誠意分數條（綠）、甩鍋指數條（紅）
4. 致命敗筆 2～3 條（公關奇蹟結局改成「做對的事」）
5. 名醫評語（＝ `expert_verdict`），18px 加引號
6. 掉粉與剩餘粉絲

### 4. 樣張專用的東西

「預覽其他結局」切換鈕只在樣張裡，正式版要拿掉。結局文字目前是範例，正式版由 AI 裁判產生。
