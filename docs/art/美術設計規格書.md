## 一、美術方向【定案】

### 1. 一句話

> **網路公審是一場 RPG 戰鬥。** 玩家是被圍攻的網紅，酸民是敵人，聲明稿是必殺技。

用像素 RPG 的介面語言（血條、對話框、指令選單、Boss 登場），包住現代社群的內容（貼文、留言、訂閱數、直播）。

### 2. RPG 對照表【定案】

| 遊戲裡的東西 | RPG 化的呈現 |
| :--- | :--- |
| 粉絲數 | HP 血條，掉粉＝扣血 |
| 炎上度 | 火焰條（敵人怒氣） |
| 廠商信任度 | MP 條 |
| 爆料事件 | Boss 登場：「BOSS 出現了！」 |
| 策略標籤 | 指令選單（技能、道具） |
| 聲明稿 | 必殺技，發布＝出招 |
| 6 種酸民 | 6 隻敵人，各有像素頭像與代表色 |
| 酸民留言 | 攻擊訊息：「激進黑粉 使出了【退訂檢舉】！效果絕佳！」 |
| 結局 | ENDING 畫面＋像素新聞卡＋診斷書 |

### 3. 社群感怎麼保住【定案】

- 留言卡保留「頭像＋暱稱＋人設標籤＋內容＋愛心數」的結構。
- 影片區有訂閱數、讚／倒讚、LIVE 標籤、播放條。
- 手機公審時，留言像直播聊天室疊在影片上。

### 4. 世界觀限制【定案】

- 場景道具用現代物件：手機、補光燈、麥克風、桌子、海報。**不用城堡、寶劍、魔法**。
- 所有品牌、平台、人物都是虛構的（見第十二章）。

### 5. 遊戲調性【定案】

荒謬搞笑為主（2026-11-25 使用者決定）。緊張感只留給倒數、扣血與警報演出；事件內容、酸民台詞、結局標題與診斷書一律走荒謬鬧劇路線。事件笑點方向見 [角色與事件庫.md](../dev/角色與事件庫.md)。

1. 程式先做灰盒版，顏色、字型、尺寸全部用第三章的 CSS 變數。

3. 新的視覺嘗試先做成樣張（`samples/像素風格樣張_vN.html`），確認後再寫進本文件。

## 三、Design Token【暫定】

數值取自樣張 v3，正式版直接複製使用。

```css
:root {
  color-scheme: dark;

  /* 底色與面板（深夜藍） */
  --night:   #0c1230;  /* 網頁底色，上面有 12px 點狀格線 */
  --panel:   #18224c;  /* 面板 */
  --panel-2: #212e63;  /* 面板內的次層：留言卡、標籤 */
  --hi:      #34458a;  /* 面板左上亮邊 */
  --lo:      #0f1738;  /* 面板右下暗邊、輸入底色 */
  --line:    #04071a;  /* 像素外框（近黑） */

  /* 文字 */
  --ink: #eef1ff;
  --dim: #97a3d6;

  /* 主色：金色＝可以按的東西 */
  --gold:    #f5b82e;
  --gold-hi: #ffe08a;
  --gold-lo: #b06f12;

  /* 語意色 */
  --red:   #ff4d5e;  /* 傷害、扣粉、LIVE、警告 */
  --flame: #ff8a1f;  /* 炎上條 */
  --cyan:  #45d0ff;  /* MP 條、鍵盤焦點框 */
  --pink:  #ff6fae;  /* 愛心數 */
  --green: #4fdc7a;  /* HP 條（低於約 73% 變紅） */

  /* 字型 */
  --px:   "Cubic11", "Noto Sans TC", sans-serif;  /* 像素字 */
  --long: "Noto Sans TC", system-ui, sans-serif;  /* 長文字，見第四章【定案】 */
}
```

**配色規則**【暫定】

- 金色只給「可以按的主要按鈕」和「選中的指令」，不要拿來裝飾。
- 紅色只表示「壞事」：傷害、扣粉、警告。
- 每個遊戲階段**不再換整體主色**（v1 的做法取消），改由結局畫面用結局色收尾（第十章）。

## 四、字型

### 1. 像素字【定案】

- **俐方體 11 號（Cubic 11）**，免費授權，支援繁體中文。
- 只把頁面用到的字做成子集，再以 base64 內嵌，維持單一 `index.html`（樣張約 30KB；正式版 2026-11-25 約 1290 字、woff2 約 53KB）。
- 子集以 [`font_subset.py`](../../.agents/skills/game-build-pipeline/scripts/font_subset.py) 從 `index.html` 實際用字產生；大量新增事件、留言或介面文字後須重跑，否則缺字會由 Noto Sans TC 補上而混用字型（見 `FP-002`）。完整字型檔不進版控。AI 模式即時產生的罕用字不在子集內，會退回 Noto Sans TC。

### 2. 字級【暫定】

像素字只有在 **12px 的倍數**最清楚，其他大小會糊。

| 字級 | 用途 |
| :--- | :--- |
| 12px | 標籤、數值說明、留言者名稱、分頁按鈕、聊天室留言 |
| 18px | 手機版對話框、手機版按鈕（會微糊，可接受） |
| 24px | 對話框、標題、主按鈕、倒數（手機） |
| 36px | Logo、倒數（電腦）、結局標題（電腦） |

### 3. 長文字用哪種字【定案】

聲明稿、爆料內文、留言內容這類長文字一律用 **Noto Sans TC**（2026-11-25 使用者決定：搞笑文案要好讀，手機上尤其重要）。標題、按鈕、數值、標籤等短字仍用像素字。程式以 `--long` 變數控制。

為了維持單檔離線可玩，Noto Sans TC 不內嵌：有網路時由 Google Fonts 載入，離線時退回系統黑體（`system-ui`），版面不得依賴其字寬。

## 五、像素 UI 元件【暫定】

| 元件 | 做法 |
| :--- | :--- |
| **面板** `.pn` | 用 4 個方向的 `box-shadow` 做出缺角的像素外框，再用 inset 做左上亮、右下暗的立體邊 |
| **面板標題** `.pn-title` | 小方塊標籤，金色字，像 RPG 視窗的標題 |
| **主按鈕** `.btn` | 金底深字＋立體邊，按下往下移 2px |
| **次按鈕** `.btn.ghost` | 深藍底白字，同樣的立體邊 |
| **指令** `.cmd` | 深色方塊，左邊小方點；選中後變金框，方點變成 ▶ 游標 |
| **血條** `.bar` | 深色槽＋上亮下暗的雙色條，寬度變化用 `steps()` 一格一格跳 |
| **留言卡** `.cm` | 48px 頭像＋暱稱＋人設色標籤＋內容＋愛心數＋扣粉數 |
| **對話框** `.dlg` | 底部長條，左邊頭像，24px 文字，右下閃爍的 ▼ |
| **輸入框** | 近黑底＋藍色內框，長文字字型 |
| **診斷書** `.doc` | 米黃紙張（`#efe6cf`）深色字，跟深藍介面做對比，一看就是「文件」 |
| **頂部狀態列**（手機） | 倒數＋HP＋炎上，固定在最上方 |
| **底部分頁**（手機） | 5 格：爆料／寫稿／公審／結局／說明，選中變金色，公審有紅點數字 |

所有可以按的東西都要有鍵盤焦點框（`--cyan` 2px 外框）。

## 六、道歉影片（主視覺）【暫定】

### 1. 畫面

- Canvas 內部解析度 **128×72**（16:9），用 `image-rendering: pixelated` 放大。
- 下方有播放條（跟 180 秒倒數連動）、影片標題、頻道名稱與訂閱數（＝粉絲數）、讚與倒讚。

### 2. 圖層（由下到上）

| 圖層 | 內容 | 連動的策略 |
| :--- | :--- | :--- |
| 背景 | 依角色各自設計的直播間（見下表） | 背景類道具（冰箱、收據、重播畫面等）局部覆蓋；鐵門、店門口、名校照片為整片換景，換景時不畫補光燈 |
| 桌子 | 依角色換材質（白色化妝台、電競桌＋RGB 鍵盤、木書桌、不鏽鋼料理台）＋麥克風 | — |
| 補光燈 | 每間直播間一種造型（見下表），畫在 `x 28～100` 以內，手機裁成正方形仍看得到；畫在背景類道具之後（燈站在牆前） | 關燈形式時改為關燈狀態 |
| 主角 | 角色坐姿，預設含淚 | 影片形式的 `expr`（鞠躬、笑、墨鏡、被抓包）與 `fx`（素顏蒼白） |
| 前景道具 | 依事件影片形式（蛋糕、珍珠奶茶、貓、律師、衛生局人員、廠商老闆、學士帽、頭套等，共 30 餘種） | 只顯示目前選中的影片形式之 `props` |
| 畫面效果 | 全黑、關燈（補光燈與 RGB 全關，只剩桌上一盞小檯燈從右下照亮主角，遠處偏冷近灰階）、變聲器雜訊（橫向錯位＋色線） | 影片形式的 `mode` |
| 字幕 | 玩家聲明稿的最後一句 | 影片形式帶 `sub` 時加前綴（例如「（機器人聲）」）；全黑時改成置中並顯示第一句 |
| 介面 | LIVE 標籤、直播聊天室（手機公審時） | — |

**角色直播間（2026-11-25 使用者決定每位角色單獨設計）**：

| 角色 | 牆面與擺設 | 補光燈 |
| :--- | :--- | :--- |
| 小艾（美妝） | 粉色條紋牆、燈泡框化妝鏡、保養品層架、愛心霓虹燈、白色化妝台 | 環形燈：粉色外殼、一圈暖白 LED 燈珠、U 形支架，位於主角正後方 |
| 阿凱（遊戲實況） | 深色房間、頂部 RGB 燈條、海報與公仔、紅黑電競椅、雙螢幕、RGB 鍵盤 | RGB 燈棒：電競椅左右各一支七彩漸層燈管，附燈架 |
| 博士 Leo（知識型） | 深綠書房、滿牆書架、寫滿算式的白板、地球儀、檯燈、木書桌 | 柔光箱：黑色箱體、白色柔光布朝向主角、三腳架，位於主角左側 |
| 饅頭（美食） | 白磁磚廚房、吊掛鍋具、黑板菜單、紅燈籠、冒煙湯鍋、不鏽鋼料理台 | 彎管夾燈：紅色燈罩斜照桌上的菜、暖黃光束，位於主角右側 |

### 3. 公審時的直播模式（手機）

畫面裁成正方形（`object-fit: cover`），隱藏字幕，留言從左下冒出，最多 3 則、每則 1 行。人物型道具（律師、衛生局人員、廠商老闆）放在 x=82～84，裁切後仍看得到。

**影片形式道具擺放原則（2026-11-25 使用者要求每個影片形式都要融合進影片）**：
- 道具的主體一律放在 `x 28～100`（手機正方形裁切範圍）內，桌上物品底部貼齊桌面 `y 57`，不浮在半空。
- 指令寫「抱著／拿著／舉著」的道具（蛋糕、貓、狗狗照片、結業證書、道歉看板）畫在主角胸前，並露出雙手；其餘道具放在主角兩側。
- 掛在牆上的背景類道具畫在補光燈後面；整片換景（鐵門、店門口、名校校園虛擬背景）不畫補光燈。

## 八、動畫【暫定】

像素風的動畫一律用 `steps()`，一格一格跳，不要平滑過渡。

| 動畫 | 做法 | 時間 |
| :--- | :--- | :--- |
| 留言卡滑入 | 從右 24px 滑入＋淡入，`steps(4)` | 0.4s |
| 聊天室留言 | 從下 12px 冒出，`steps(3)` | 0.35s |
| 血條變化 | 寬度 `steps(12)` | 0.6s |
| 畫面震動 | 扣粉超過 5 萬時，整個戰場左右晃 | 0.3s |
| 倒數變紅閃爍 | 剩 30 秒，`steps(2)` 閃爍 | 0.5s 循環 |
| 對話框 ▼ | 閃爍 | 0.8s 循環 |
| HP 扣血數字 | 手機狀態列的 HP 數字短暫變成紅色扣血量 | 1.2s |

`prefers-reduced-motion` 開啟時，震動、閃爍、滑入全部關掉。

## 九、版面【暫定】

### 1. 電腦版（寬度大於 1080px）：三欄一次看完

```
┌ Logo ──────────────────────────────────── 倒數 ┐
├ 左：狀態／Boss 貼文／三大質疑 ┬ 中（>=1280px 寫稿／裁決為雙區並排）：道歉影片 ｜ 指令與聲明稿／判決 ┬ 右：留言區（限高捲動） ┤
├ 對話框（攻擊訊息） ───────────────────────────────────────────────────────────────────────────────────────────────┤
└ 結局：蓋在畫面上的全螢幕層（96vw），可按「回到公審」或 Esc ───────────────────────────────────────────────────────┘
```

- 整體容器 `.wrap` 與 `.res-in` 採 `max-width: 96vw` 滿版延展；三欄彈性比例為 `1081~1279px` 約 `23:50:27`、`>=1280px` 約 `21:54:25`。
- `>=1280px` 在寫稿（`draft`）與裁決（`verdict`）階段，中欄改為左（`0.88fr` 道歉影片）右（`1.12fr` 策略指令＋聲明稿或裁判長判決）並排，壓低整體高度以在一屏內看完（含底部對話框）；`1081~1279px` 裁決頁則將判決面板置頂於影片上方。
- 右欄留言區以 `clamp(360px, calc(100vh - 300px), 660px)` 彈性限高捲動，未開播時顯示等待提示。
- 寬度 761～1080px：左欄移到下方變兩欄。

### 2. 手機版（寬度 760px 以下）：一次一個階段，不捲動

```
┌ 頂部狀態列：倒數｜HP｜炎上 ┐
│                          │
│   目前階段的畫面          │
│                          │
└ 底部分頁：爆料 寫稿 公審 結局 說明 ┘
```

| 階段 | 畫面內容 |
| :--- | :--- |
| 爆料 | Boss 貼文＋三大質疑＋「接招！開始寫聲明」 |
| 寫稿 | 小影片＋指令（兩欄、不顯示說明小字）＋聲明稿＋發布鈕 |
| 公審 | 方形直播畫面＋聊天室＋對話框＋「查看裁判長判決」鈕＋下方直接展開完整「炎串 · 留言區」；點判決鈕進入裁決頁後對話框置於最上方提示撤回倒數，接著顯示裁判面板與「緊急撤回」「認了，看結局」，下方保留完整留言區 |
| 結局 | 結局標題＋新聞卡＋診斷書＋重新挑戰（這頁可以捲動） |

- 階段改變時自動切換分頁；玩家也可以點分頁回去看。
- **專注寫稿模式**：點聲明稿輸入框時隱藏指令區，讓字幕預覽和輸入框留在鍵盤上方（實機效果待確認）。
- 頂部和底部都要加上手機安全區域的邊距。

### 3. AI 公關名醫診斷書

米黃紙張樣式，內容依序：

1. 標題「AI 公關名醫診斷書」＋病歷號
2. 病患（玩家所選角色名稱）、診斷（＝ AI 回傳的 `core_attitude`）
3. 誠意分數條（綠）、甩鍋指數條（紅）
4. 致命敗筆 2～3 條（公關奇蹟結局改成「做對的事」）
5. 名醫評語（＝ `expert_verdict`），18px 加引號
6. 掉粉與剩餘粉絲

### 4. 樣張專用的東西

「預覽其他結局」切換鈕只在樣張裡，正式版要拿掉。結局文字目前是範例，正式版由 AI 裁判產生。
