# 角色與事件庫（Characters & Crisis Events）

> **文件用途**：記錄可選角色、10 則標準危機事件，以及每則事件的必答質疑、關鍵字與專屬策略效果。程式中的 `CHARACTERS` 與 `CRISIS_EVENTS` 資料一律以本檔為準；計分公式見 [實作規格書.md](實作規格書.md) 第四章。
>
> **調性【定案】**：荒謬搞笑為主，緊張感只靠倒數與扣血演出（2026-11-25 使用者決定）。事件要「越想越好笑」，但人物、平台、品牌一律虛構，不影射真實人物或真實事件。

---

## 一、角色（開場自選）【暫定】

玩家在 `STATE_SELECT` 從 4 位角色中選一位。每位角色有不同初始數值與一條專屬規則，讓同一份聲明稿套在不同角色身上會有不同結果。數值為初版，實際手感待 TD 實作後再調。

| 代碼 | 名字 | 人設 | 初始粉絲 | 初始廠商信任 | 專屬規則 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `CHAR_IVY` | 小艾 Ivy | 美妝網紅，精緻完美、業配接不完 | 1,500,000 | 50 | 業配相關事件掉粉 ×1.3；回應退款題時廠商信任額外 +10 |
| `CHAR_KAI` | 阿凱 Kai | 遊戲實況主，嘴砲、死忠粉多 | 1,200,000 | 30 | 死忠粉護盾：最終掉粉 ×0.8；聲明稿出現髒話直接觸發紅旗 `profanity` |
| `CHAR_LEO` | 博士 Leo | 知識型影片創作者，理性、愛講道理 | 900,000 | 40 | 裁判判定有邏輯矛盾（`contradiction`）時誠意 -20；寫出具體數據或時程時誠意 +10 |
| `CHAR_MANTOU` | 饅頭 Mantou | 美食部落客，親民、自己開店 | 1,000,000 | 35 | 食安事件掉粉 ×1.5；提出停業或公開檢驗時炎上度額外 -10 |

- 四位角色共用表情集：正常、含淚、心虛、灰階（身敗名裂）、墨鏡（黑紅巨星）、微笑（公關奇蹟）、被抓包（隱藏結局）。點陣規格見 [美術設計規格書.md](../art/美術設計規格書.md) 第七章。
- 律師為共用配角，不可選。

## 二、事件資料結構

```javascript
{
  id: "EVENT_01",
  title: "事件標題",
  characters: ["CHAR_IVY", "CHAR_KAI"],   // 可抽到此事件的角色；["ALL"] 表示通用
  tags: ["sponsor"],                        // 套用角色專屬規則用：sponsor（業配）/ food（食安）
  bg_alert: "爆料內文",
  inquiries: [
    { q: "質疑一", keywords: ["關鍵字", "..."] },   // 離線評分：稿中出現任一關鍵字視為「有回應」
    { q: "質疑二", keywords: ["..."] },
    { q: "質疑三", keywords: ["..."] }
  ],
  initial_flame: 75,
  tactic_overrides: { "TACTIC_MEDICAL": { shirking: 20, red_flag: "guilt_trip" } },  // 本事件專屬策略效果
  offline_comments: [ /* 每種人設 2 則，共 12 則；離線模式隨機抽 6 則 */ ]
}
```

## 三、10 則標準事件【暫定】

關鍵字只列代表詞，實作時可再擴充同義詞。「專屬陷阱」是本事件中效果與一般規則不同的策略。

### EVENT_01｜自創潮牌原來是 39 元同款
- **可抽角色**：小艾、阿凱｜**標籤**：`sponsor`｜**初始炎上**：75
- **爆料**：標榜「100% 台灣原創獨立打版」的潮牌 T 恤一件 1,680 元，被爆料版網友比對出購物平台「便宜寶」上 39 元同款，連「洗滌請用冷水」的外文吊牌都沒剪。
- **必答質疑**：
  1. 到底是不是貼牌貨？（承認、貼牌、代工、同款）
  2. 願不願意全額退款？（退款、退費、全額、賠償）
  3. 為什麼瘋狂刪質疑留言？（刪留言、刪文、封鎖、恢復留言）
- **專屬陷阱**：「推給外包廠商」甩鍋 +35（網友早就查到工廠是你表哥開的）。
- **笑點方向**：吊牌、39 元、「設計靈感來自夢境」。

### EVENT_02｜純情人設同時交往 4 人
- **可抽角色**：小艾、博士 Leo｜**初始炎上**：80
- **爆料**：主打「母胎單身、只談心靈成長」的創作者，被前任在爆料版貼出對話紀錄：同時交往 4 人，還把粉絲送的生日蛋糕轉送給其中 3 位，蠟燭都沒換。
- **必答質疑**：
  1. 對話紀錄是不是真的？（屬實、承認、是真的、對話紀錄）
  2. 有沒有挪用粉絲禮物？（禮物、蛋糕、歸還、粉絲送的）
  3. 純情人設是不是演的？（人設、演的、經營、真實的我）
- **專屬陷阱**：「保留法律追訴權」紅旗加倍（你要告的是你自己的前任們）。
- **笑點方向**：4 人行事曆、同一句情話複製貼上 4 次。

### EVENT_03｜投資的手搖飲珍珠掉水槽
- **可抽角色**：饅頭、小艾｜**標籤**：`food`｜**初始炎上**：85
- **爆料**：網紅投資的排隊手搖飲「饅頭茶研所」，離職員工上傳影片：珍珠掉進水槽撈起來繼續舀，過期鮮奶改標籤再用，衛生局已經出發。
- **必答質疑**：
  1. 事前知不知情？（知情、不知情、知道、管理疏失）
  2. 喝到的消費者怎麼賠？（賠償、退費、醫療費、補償）
  3. 門市要不要停業受檢？（停業、暫停營業、受檢、檢驗）
- **專屬陷阱**：「曬身心科病歷」觸發紅旗 `guilt_trip`，網友：「生病的是喝到的人吧」。
- **笑點方向**：「珍珠只是想回家」、水槽 Q 彈認證。

### EVENT_04｜代言的零卡氣泡水，冰箱裡全是別牌
- **可抽角色**：小艾｜**標籤**：`sponsor`｜**初始炎上**：70
- **爆料**：說「每天喝 3 瓶、喝到變美」的代言氣泡水，開箱影片背景的冰箱被放大 400%，裡面整排都是競品，代言瓶只有一瓶，而且還沒開。
- **必答質疑**：
  1. 你到底有沒有在喝？（有在喝、沒有在喝、承認、其實）
  2. 業配費要不要退？（業配費、退還、廠商、代言費）
  3. 以前的推薦是不是都是假的？（推薦、真心、業配標示、以後）
- **專屬陷阱**：「全額認錯退款」但沒提到業配費，仍判口說無憑（退的對象是廠商不是粉絲）。
- **笑點方向**：冰箱放大鏡、「那瓶是供起來拜的」。

### EVENT_05｜直播忘關鏡頭，罵粉絲是盤子
- **可抽角色**：阿凱｜**初始炎上**：80
- **爆料**：實況結束後以為下播了，鏡頭還開著 47 分鐘，被錄到「這些盤子斗內真好賺」「明天再哭一次窮」，片段在炎串被轉了 20 萬次。
- **必答質疑**：
  1. 是不是在罵粉絲？（承認、是我說的、不該、盤子）
  2. 斗內要不要退？（斗內、退款、退還、贊助）
  3. 平常的哭窮是不是演的？（哭窮、演的、真實狀況、收入）
- **專屬陷阱**：聲明稿出現髒話時，阿凱專屬規則的紅旗再額外炎上 +10（「又來？」）。
- **笑點方向**：47 分鐘、「我在練習反派台詞」。

### EVENT_06｜抽獎抽中的是自己的分身帳號
- **可抽角色**：阿凱、饅頭｜**初始炎上**：70
- **爆料**：百萬抽獎直播，大獎得主「路人小明123」被網友抓到是你自己的分身，頭貼是你家的貓，連貓都承認了（牠在直播裡亂入）。
- **必答質疑**：
  1. 分身帳號是不是你的？（分身、我的帳號、承認、小明）
  2. 獎品要怎麼處理？（重抽、補發、獎品、公開抽獎）
  3. 以前的抽獎是不是也內定？（以前、內定、公開名單、第三方）
- **專屬陷阱**：「推給外包廠商」直接判邏輯矛盾 `contradiction`（外包廠商不會養你的貓）。
- **笑點方向**：貓、「小明是我的內在小孩」。

### EVENT_07｜知識影片逐字翻譯外國頻道
- **可抽角色**：博士 Leo｜**初始炎上**：75
- **爆料**：號稱「自己讀了 200 篇論文整理」的科普影片，被發現是外國頻道逐字翻譯，連原作者講的冷笑話和「記得訂閱我的頻道」都一起翻了。
- **必答質疑**：
  1. 是不是抄襲？（抄襲、翻譯、承認、未經授權）
  2. 要不要向原作者道歉並下架？（下架、道歉、原作者、授權）
  3. 那 200 篇論文是真的有讀嗎？（論文、有讀、沒有讀、誇大）
- **專屬陷阱**：「曬身心科病歷」觸發紅旗 `guilt_trip` 並判邏輯矛盾（「生病還能翻譯得這麼準？」）。
- **笑點方向**：連片尾都翻、「這叫跨國知識交流」。

### EVENT_08｜自稱哈佛畢業，其實是哈佛補習班
- **可抽角色**：博士 Leo｜**初始炎上**：70
- **爆料**：簡介寫「哈佛畢業」，被同學爆料是台北某補習班「哈佛美語」的結業證書，上面還有一個獎狀貼紙寫「上課很認真」。
- **必答質疑**：
  1. 到底是哪間哈佛？（補習班、承認、不是哈佛大學、誤導）
  2. 要不要修改所有簡介與影片？（修改、更正、簡介、下架）
  3. 業配合約裡的學歷要不要跟廠商說明？（廠商、合約、說明、賠償）
- **專屬陷阱**：「揚言對造謠者保留法律追訴權」紅旗加倍（證書是你自己上傳的）。
- **笑點方向**：獎狀貼紙、「我從沒說是哪個哈佛」。

### EVENT_09｜五星推薦的餐廳，原來是自己開的
- **可抽角色**：饅頭｜**標籤**：`food`、`sponsor`｜**初始炎上**：75
- **爆料**：「今年吃過最感動的一家」五星評價影片，被查到店是自己開的，還請工讀生用 30 個帳號灌好評，其中一則評論寫「老闆饅頭很帥」，署名是饅頭本人。
- **必答質疑**：
  1. 為什麼沒揭露是自己的店？（揭露、自己的店、承認、隱瞞）
  2. 灌好評的帳號要不要刪？（灌好評、假評論、刪除、帳號）
  3. 其他推薦影片有沒有利益關係？（其他、業配、公開、利益）
- **專屬陷阱**：「推給外包廠商」甩鍋 +30（工讀生就是你的外包）。
- **笑點方向**：署名自己、「我只是太愛這家店」。

### EVENT_10｜流浪動物募款，收據是小畫家做的
- **可抽角色**：通用（全部角色）｜**初始炎上**：85
- **爆料**：直播說要把一個月收入全捐流浪動物之家，三個月後網友問收據，貼出來的收據字型是新細明體，印章歪掉，「流浪動物之家」還寫成「流浪動物之加」。
- **必答質疑**：
  1. 錢到底捐了沒？（捐了、還沒捐、捐款、匯款）
  2. 能不能公開真正的收據與帳目？（收據、帳目、公開、明細）
  3. 為什麼要做假收據？（假收據、偽造、小畫家、承認）
- **專屬陷阱**：「全額認錯退款」改判為「立刻補捐」效果，但沒寫補捐金額或時間仍判口說無憑。
- **笑點方向**：「之加」、狗狗也在等收據。

## 四、事件抽取規則

1. 依玩家選的角色，從 `characters` 包含該角色或為 `ALL` 的事件中隨機抽一則；同一角色每位至少可抽到 4 則。
2. 同一個瀏覽器連續兩局不抽到同一則（以 `localStorage` 記上一局事件編號）。
3. 新增事件只需在本檔與 `CRISIS_EVENTS` 增加一筆資料，不改程式邏輯。
