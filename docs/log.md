- 列出的方向：擬真介面、台式八卦週刊拼貼、迷因醜美學、復古電腦當機風、新聞直播棚。

## [2026-11-07] 決策 | 美術風格改為「像素 RPG × 社群」

- 由使用者提供的像素風 UI 參考圖觸發（取 UI 元件的感覺，不取奇幻世界觀）。
- 核心比喻：網路公審是一場 RPG 戰鬥。
  - 粉絲＝HP、炎上度＝怒氣條、廠商信任＝MP
  - 爆料＝Boss 登場、策略＝技能與道具、聲明稿＝必殺技
  - 6 種酸民＝6 隻敵人，留言＝攻擊訊息（「激進黑粉 使出了【退訂檢舉】！效果絕佳！」）
- 社群感靠內容結構維持：頭像＋暱稱＋內容＋愛心數、訂閱數、倒讚、LIVE 標籤。
- 場景道具用現代物件（手機、補光燈、筆電、麥克風），不用城堡寶劍。
- 中文像素字型用「俐方體 11 號」；長文字可能改用一般字型，待比較。
- 角色和頭像用程式畫點陣圖，不用圖檔。
- 影響文件：[美術設計規格書.md](art/美術設計規格書.md) 需改寫（尚未改）

## [2026-11-07] 討論 | 手機版排版改法

- 問題：電腦版是「一眼看完全部」，手機版只是拆成一長條往下捲，看不到血條在掉，戰鬥感和壓迫感都不見；打字時鍵盤會蓋住半個畫面。
- 提出的做法：
  1. 頂部固定精簡狀態列（倒數、HP、炎上度）
  2. 依遊戲階段只顯示當下需要的內容（爆料 → 寫聲明 → 公審 → 結局）
  3. 公審時留言像直播聊天室一樣疊在影片下半部飄上來
  4. 底部 RPG 分頁選單（爆料／指令／留言）
  5. 點輸入框進入專注寫稿模式，避開鍵盤
- 目前傾向：2 加 3，電腦版維持三欄不變。使用者同意先做手機版 v2 樣張試試。
